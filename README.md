# 🫒 המסיק – מעקב מסיק זיתים

אפליקציית אנדרואיד פשוטה למעקב אחרי המסיק: דולבים, משקל בבית הבד, ליטרים, אחוזי שמן ועלויות.
כל המידע נשמר **רק בטלפון**. אין שרת ואין עלויות אירוח.

## מה יש באפליקציה
- **מסיקים**: לכל שנה מסיק נפרד ("מסיק 2026"), עם מחירי בית הבד (לק״ג ולמיכל).
- **יום מסיק**: תאריך, חלקה, סוגי זיתים, ולכל סוג דולבים, ק״ג בבית הבד, ליטר שמן ומיכלים. בנוסף פועלים ועלות לפועל ליום.
- **סטטיסטיקות**: גרף עמודות (אחוז שמן, ק״ג, ליטר, ק״ג לדולב, עלות לליטר) וגרף קווי של אחוז השמן לאורך המסיק לכל סוג. חיתוכים לפי סוג, חלקה, חלקה וסוג יחד, שנה ויום, עם סינון לפי מסיק, חלקה וסוג.
- **וואטסאפ**: הודעת סיכום בעברית למסיק כולו או ליום בודד.
- **אקסל**: ייצוא של מסיק אחד או של כל המסיקים, עם גיליונות סיכום.
- **💬 עוזר AI**: צ׳אט בעברית (Claude Haiku 5.5) שמכיר את כל נתוני המסיקים ועונה גם על שאלות כלליות על זיתים. צריך אינטרנט ומפתח API מ-console.anthropic.com, שמוזן פעם אחת בהגדרות ונשמר רק בטלפון. משלמים לפי שימוש.
- **גיבוי**: שליחת קובץ גיבוי ושחזור ממנו (למשל במעבר לטלפון חדש).
- הוספה, שינוי שם והסתרה של סוגי זיתים וחלקות.

## מה מזינים ומה מחושב
| מזינים ✏️ | מחושב 🧮 |
|---|---|
| דולבים, ק״ג בבית הבד, ליטר שמן | **אחוז שמן** = ליטר × 0.916 ÷ ק״ג (לפי משקל) |
| | **ק״ג לדולב** = ק״ג ÷ דולבים |
| (אפשר לתקן ידנית) | **מיכלים** = ק״ג שמן ÷ 18, מעוגל למעלה |
| פועלים, עלות לפועל ליום | **עלות פועלים** |
| מחיר לק״ג ומחיר למיכל (פעם אחת למסיק), לפני או כולל מע״מ | **שולם לבית הבד**: לפני מע״מ, מע״מ (18% כברירת מחדל), סה״כ לתשלום. אפשר להזין סכום ידני, כולל או לפני מע״מ |
| | סה״כ ליטר, עלות כוללת, עלות לליטר |

כשבאותו יום נקטפו כמה סוגים, בסטטיסטיקות לפי סוג העלויות של היום מתחלקות בין הסוגים לפי המשקל.

## התקנה על הטלפון
בכל push ל-GitHub נבנה קובץ APK אוטומטית (GitHub Actions) ומתפרסם תחת **Releases**.
פותחים את ה-Release בטלפון, מורידים את קובץ ה-`.apk` ומתקינים אותו.
עדכון לגרסה חדשה מותקן מעל הגרסה הקודמת ושומר את כל הנתונים.

## פיתוח
```bash
npm install
npm test            # בדיקות לחישובים
npm run typecheck
npx expo start      # הרצה עם Expo
npx expo export -p web   # תצוגה בדפדפן לבדיקות (נשמר ב-localStorage)
```
הטכנולוגיה: Expo SDK 58 (React Native), Expo Router, ו-`expo-sqlite/kv-store` לשמירה מקומית.

הקוד:
- `src/lib/calc.ts`: כל החישובים
- `src/lib/summary.ts`: הודעות הוואטסאפ
- `src/lib/excel.ts`: ייצוא לאקסל
- `src/app/`: המסכים
